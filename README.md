# prettyplease-any.rs

Pretty print individual items and expressions, using the [`prettyprint` crate] undearneath.

Necessary because prettyprint only provides functionality to print an entire [`syn::File`](https://docs.rs/syn/3.0.6/syn/file/struct.File.html).
The [`prettyprint::unparse(&File)`](https://docs.rs/prettyplease/0.3.0/prettyplease/fn.unparse.html) function is the only item in the whole `prettyplease` crate.

This crate works around this issue and offers a [`PrettyPlease`](https://docs.rs/prettyplease-any/latest/prettyplease_any/trait.PrettyPlease.html) trait for most syn types.

The implementation makes some assumptions about the formatted code,
so it could break if prettyplease makes major changes to its output.


[`prettyprint` crate]: https://github.com/dtolnay/prettyplease
